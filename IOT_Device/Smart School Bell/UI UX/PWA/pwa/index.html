Power Recovery
Setup Checklist
Configure your PC so the bell system restarts automatically after a power cut — no manual action needed.
Why this matters: Schools often face sudden power outages. With the right BIOS and Windows settings, your PC boots itself and Jenix SchoolBell resumes the bell schedule automatically — even after midnight power cuts.
Enable "Power On After AC Loss" in BIOS
BIOS → Power Management → AC Power Loss → Power On
Enable Windows Auto Login (no password on boot)
Run netplwiz → uncheck "Users must enter password"
Verify correct System Date & Time
Settings → Time & Language → Set time automatically → On
✅ After these 3 settings: Power cut → PC boots → Windows logs in → Jenix SchoolBell starts → bells resume. Fully automatic.

Power Recovery Configuration
Ensure your system auto-recovers from power cuts:
1. BIOS: Power On After AC Loss
Power Management → AC Power Loss → Power On
2. Windows: Auto Login (no password)
Press Win+R → type netplwiz → uncheck "Users must enter a password"
3. Windows: Sync time automatically
Settings → Time & Language → Set time automatically → On
✅ With all 3 set: power cut → PC boots → auto login → Jenix starts → bells resume. Fully automatic.
