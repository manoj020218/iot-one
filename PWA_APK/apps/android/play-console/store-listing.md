## Full description (max 4000 characters)

```
Jenix One is the single app for setting up and running every device in the
Jenix smart product line — from a home Wi-Fi bell system to an industrial
water-tank monitor.

SUPPORTED DEVICES
• Smart Tank Guard — water tank level monitoring and alerts
• Smart School Bell — scheduled ring times, live PA announcements, and
  push-to-talk over Wi-Fi
• QRunlock — RF-controlled smart door lock
• Nurse Call Receiver — call-station alerts for care facilities
• Smart RF Bridge — RF-to-cloud bridging for existing hardware
• Smart Token Dispenser — queue-management token printing
• Token Display — live queue number display
• SOS Siren — emergency alert siren control
• Smart Streamer — networked audio/video streaming device

SET UP A DEVICE IN MINUTES
Add a new device with Smart Mode (automatic discovery over Bluetooth) or,
for devices that support it, AP Mode (connect directly to the device's own
Wi-Fi hotspot) — no separate configuration tool needed.

ONE HOME, EVERY DEVICE
See every device's live status from a single Home dashboard, organize
devices into scenes, and get notified the moment something needs attention.

BUILT FOR REAL SITES
Jenix One is designed for people actually installing and running this
hardware — schools, clinics, factories, and apartment buildings — not just
demoing it. Local-network fallbacks and clear setup steps mean a device
that's hard to reach from the cloud is still easy to bring online from the
same room.
```
